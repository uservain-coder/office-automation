# 脱敏与合规自检（发布前）

本仓库所有示例数据均为虚构，发布前已逐条自检。

## 一、脱敏对照清单
| 真实信息类型 | 仓库中的处理 | 示例 |
|--------------|--------------|------|
| 真实姓名 | → 虚构人名 | 张三 / 李四 / 王五 / 赵六 / 钱七 / 孙八 |
| 真实公司 | → 泛指名称 | 某科技公司 |
| 真实金额 | → 明显虚构值 | 12000 / 9500 / 199（示例用） |
| 电话 / 地址 | → 一律不出现 | 无 |
| 内部业务数据 | → 通用示例 | 区域 / 部门 / 销售额 等通用字段 |

> 真实客户交付时，客户原始数据**绝不入库**，只在本地处理，完事即清。

## 二、合规自检清单
| 检查项 | 结论 | 说明 |
|--------|------|------|
| 含破解 / 外挂 / 刷单 / 抢票代码或暗示 | ✅ 通过 | 无，脚本均为合法办公场景 |
| 涉及爬取非公开数据 / 突破 robots | ✅ 通过 | 无网络爬取逻辑 |
| 泄露真实个人敏感信息 | ✅ 通过 | 全部脱敏虚构 |
| 措辞为「远程技术服务」而非「虚拟资源出售」 | ✅ 通过 | README / 服务说明均用「定制技术服务」 |
| 免责声明完整（合法用途 + 不接违规单） | ✅ 通过 | README 底部免责声明已写明 |

## 三、红线（对外接单同样适用）
- 不接代写作业（如需，改「辅导向」）
- 不碰外挂 / 破解 / 刷单 / 抢票
- 爬虫只采公开数据、守 robots
- 收 30%~50% 定金再开工，分段演示收尾款
